# Weather

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `weather`, which looks up the current weather and the forecast, and can also look up air quality, past weather, marine conditions, climate trends and elevation. The data comes from [Open-Meteo](https://open-meteo.com) (no key needed); when the current forecast fails, the tool falls back to [wttr.in](https://wttr.in).

## Parameters

The tool takes these parameters:

| Parameter | Description |
|---|---|
| `location` | Required. The city, place name or airport code to look up. Places outside China are found more accurately in English or in the local script (for example `Tokyo` or `東京`); common Chinese place names (for example `东京`, `纽约` …) are converted by the script automatically. |
| `query` | The kind of lookup: `forecast` (the default: current weather plus a daily forecast), `air_quality`, `historical`, `marine`, `climate` or `elevation`. |
| `days` | The number of forecast days, from 1 to 16. The default is 3 (at most 7 for air quality and marine conditions). |
| `start_date`, `end_date` | The first and last dates to look up. They are required for `historical` (from 1940 up to two days ago) and `climate` (up to 2050); one lookup covers at most 31 days. |
| `country_code` | A two-letter country code, used to pick the right place among places with the same name. |
| `format` | The output format: `md` (the default) or `json` (for scripts that call the tool through `miyu call`). |

## Notes

Keep the following in mind when you use the tool:

- The place the tool picks is not always the right one: the end of the output lists other places with the same name, and if the chosen place is a small one with no population data, the output carries a warning.
- The tool uses only the Python standard library. Place names are cached for 30 days and weather for 10 minutes, both in `MIYU_CACHE_DIR`.
- Air quality, past weather, marine conditions and climate are model data, and the output names the source; when you relay them, do not present them as measurements.
