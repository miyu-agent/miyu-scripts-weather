# 天气查询

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `weather`，可以查询实时天气和预报，也可以查询空气质量、历史天气、海况、气候趋势和海拔。数据来自 [Open-Meteo](https://open-meteo.com)（不需要密钥）；查询实时预报失败时，工具会改用 [wttr.in](https://wttr.in)。

## 参数

工具的参数如下：

| 参数 | 说明 |
|---|---|
| `location` | 必须填写。要查询的城市、地名或机场代码。国外的地方用英文或当地文字（例如 `Tokyo`、`東京`）查得更准；常见的中文地名（例如 `东京`、`纽约`……），脚本会自动转换。 |
| `query` | 查询的类型：`forecast`（默认，实时天气加逐日预报）、`air_quality`、`historical`、`marine`、`climate`、`elevation`。 |
| `days` | 预报的天数，范围是 1–16，默认是 3（空气质量和海况最多 7 天）。 |
| `start_date`、`end_date` | 查询的起止日期。使用 `historical`（从 1940 年起，到两天前为止）和 `climate`（到 2050 年为止）时必须填写；一次最多查询 31 天。 |
| `country_code` | 两位的国家代码，用来在同名的地点里选出正确的那一个。 |
| `format` | 输出的格式：`md`（默认）或 `json`（供通过 `miyu call` 调用的脚本使用）。 |

## 注意

使用这个工具时，要注意以下几点：

- 工具选中的地点不一定正确：输出的末尾会列出同名的其他地点；如果选中的是一个没有人口数据的小地方，输出会带一条警告。
- 这个工具只使用 Python 标准库。地名缓存 30 天，天气缓存 10 分钟，都放在 `MIYU_CACHE_DIR`。
- 空气质量、历史天气、海况和气候都是模型数据，输出里写明了出处；转述时不要把它们当成实测数据。
